How to add a new entry (do this daily)

  1. Open blog.html in a text editor.
  2. Find the <!-- ADD NEW ENTRIES ABOVE THIS LINE --> comment inside <div class="journal-entries">.
  3. Copy one <article class="journal-entry">...</article> block, paste it just above that comment (newest entries stay at the top).
  4. Update the date, title, body text, and tags for today.
  5. Save the file and refresh the page in your browser.
18 July 2026 — Cycle Day 2 (Menses)
First Muse 2 recording + meditation band breakdown

Got the Muse 2 → Mind Monitor pipeline working end to end after a few Bluetooth connection issues (turned out the official Muse app was still running in the background and blocking the connection). First real 3.4-minute resting-state recording produced a frontal alpha asymmetry (FAA) score of −0.78, right-lateralised.

Also ran a 3-minute meditation session through the full band breakdown script: Beta was dominant throughout (Alpha − Beta = −0.13, Theta − Beta = −0.34), meaning the session stayed more alert/active than settled. Gamma read highest of all, but that's most likely a muscle/jaw-tension artifact on dry electrodes rather than a real meditative-gamma state, so treating that one with caution.

Next: record a session in the late follicular phase (~day 10–14) and one in the luteal phase (~day 21–28) to build the phase comparison. Also starting a daily morning meditation habit and tracking Alpha–Beta trend across sessions over time.
